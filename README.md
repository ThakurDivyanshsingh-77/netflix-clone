# Streamora — Educational Streaming UI Demo

Streamora is an independent static frontend concept for exploring responsive streaming-platform interfaces. It is a fictional product and does not provide accounts, subscriptions, playback, or personal-information collection.

## Features

- Responsive semantic HTML and CSS layout
- Accessible navigation, focus states, and expandable FAQ content
- CSS-generated visual treatments with no external media dependencies
- Reduced-motion support
- Explicit educational and non-affiliation disclosures

## Run locally

This project has no build step or runtime dependencies. Open `index.html` in a browser, or serve the folder with any static file server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Technology

HTML and CSS only. The page uses Google Fonts for typography when network access is available; the layout remains functional with browser fallback fonts.

This website is an independent educational UI demonstration and is not affiliated with or endorsed by any streaming service.
